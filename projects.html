Bookshelf

Vue 3 · JavaScript · Bootstrap · PHP · MariaDB · Hardcover API

Bookshelf er mit eksamensprojekt på tredje semester. Det er en webapplikation til at organisere bøger og lydbøger i en personlig samling. Jeg har udviklet brugergrænsefladen med Vue 3 og Bootstrap og integreret Hardcover's GraphQL API, så man kan søge efter bøger og hente information om blandt andet forfattere og bogserier. Projektet har især givet mig mulighed for at arbejde med genanvendelige komponenter, dynamisk indhold og interaktive funktioner.

Bookshelf is my third-semester exam project: a web application for organising a personal collection of books and audiobooks. I developed the user interface with Vue 3 and Bootstrap and integrated Hardcover's GraphQL API to search for books and retrieve details such as authors and series. The project has given me the opportunity to focus on reusable components, dynamic content and interactive functionality.

Hesselgaard – Glamping

Webdesign · Mobile-first · UX · Group project

Hesselgaard er et gruppeprojekt fra min uddannelse, hvor vi udviklede en digital løsning til en glampingdestination på Fyn. Vi arbejdede med at præsentere stedets ophold, aktiviteter og faciliteter på en overskuelig måde og samtidig formidle den rolige, naturnære atmosfære. Projektet havde fokus på brugeroplevelse, navigation og et responsivt design med en mobile-first tilgang.

Hesselgaard is a group project from my studies, where we developed a digital solution for a glamping destination on Funen, Denmark. We focused on presenting stays, activities and facilities clearly while reflecting the location's calm, nature-oriented atmosphere. The project focused on user experience, navigation and responsive design using a mobile-first approach.

Discord Bot – Random Facts

JavaScript · Node.js · discord.js

Jeg har lavet en Discord-bot med JavaScript, Node.js og discord.js for at eksperimentere med programmering uden for traditionelle websites. Botten reagerer på kommandoen !randomfact og sender en tilfældig fakta. Projektet har givet mig erfaring med eventbaseret programmering, kommandohåndtering og integration med Discord.

I built a Discord bot using JavaScript, Node.js and discord.js to experiment with programming outside traditional websites. The bot responds to the !randomfact command with a random fact. The project has given me experience with event-driven programming, command handling and integration with Discord.
